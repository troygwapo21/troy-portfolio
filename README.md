# 🌐 Troy P. Villaruel — Personal Portfolio Website

**Video Editor • Affiliate Creator • Vibe Coder**

🔗 **Live Website:** [https://troy-portfolio-sigma.vercel.app](https://troy-portfolio-sigma.vercel.app)

---

## ✨ Features
- **Clean Baby Blue & White Theme:** Modern, professional glassmorphic UI.
- **Smooth Scroll Fade-In Animations:** Powered by `IntersectionObserver` for buttery-smooth transitions as you scroll.
- **Interactive Portfolio Filter:** Filter completed projects by **Video Editing**, **Affiliate Campaigns**, and **Vibe Coding**.
- **Animated Skill Bars:** Progress indicators that animate smoothly into view.
- **Direct Social Connect:** Quick links to Facebook, TikTok, and Instagram.

## 📂 Project Structure
- `index.html` — Main website structure and content (Hero, About, Skills, Projects Done, Contact)
- `style.css` — Custom styling, Baby Blue & White color palette, responsive layout, and animations
- `script.js` — Scroll fade-in observer, navbar active state, mobile menu, and project category filter
